# My Story

Story data for Story Manager (schemaVersion 1).

- Story: The Last Gardener
- Volume 1: Sowing Seeds (Gieo mầm)
- Chapter 1: The Primeval World (Nguyên giới)
- VI and EN chapter files are copied byte-for-byte from the supplied Markdown files.
- Initial edition status: VI final; EN review. These statuses can be changed in Story Manager. No reviewed translation-source commit is claimed.
- Character, milestone, genre and tag metadata is seeded from the supplied chapter and synopsis.
- Artwork: https://github.com/nguyenvanhoang0/my-story-assets

Clone both repositories next to the app, choose this repository in Settings, and bind the artwork checkout in the image library. The deer image is the Volume 1 cover; the golden tree is the story cover. Image references are pinned to artwork commit ca03eccf5f9b44946765ec96aeb42d96e920f3c1.

Saved statistics are generated locally when Check is run in Story Manager.
